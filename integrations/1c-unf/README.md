# Расширение обмена для 1С:УНФ 3.0

Исходный модуль предназначен для клиент-серверной 1С:УНФ 3.0.13.363. Он отправляет проведённые расходные накладные в `https://sborka-zakaza-mavicykt.amvera.io/api/integrations/1c/expense-invoices`.

## Состав расширения

В расширении конфигурации создаются:

1. общий серверный модуль `СладкаяПланетаОбменСервер` с флагами «Сервер» и «Вызов сервера»;
2. строковая константа `СладкаяПланетаКлючОбмена` длиной не менее 64 символов;
3. подписка на событие `ПриЗаписи` документа `РасходнаяНакладная`, обработчик `СладкаяПланетаОбменСервер.ПриЗаписиРасходнойНакладной`.

Код обработчика находится в [СладкаяПланетаОбменСервер.bsl](./СладкаяПланетаОбменСервер.bsl).

## Безопасный порядок подключения

1. Создать резервную копию информационной базы.
2. Собрать расширение на той же версии платформы, что используется сервером 1С.
3. Проверить расширение сначала на копии базы.
4. Задать один и тот же секрет в `ONEC_EXCHANGE_TOKEN` веб-сервиса и в константе `СладкаяПланетаКлючОбмена`.
5. Провести тестовую расходную накладную и проверить ответ веб-сервиса и журнал регистрации `СладкаяПланета.Обмен1С`.
6. Только после проверки подключить расширение в рабочей базе.

Ошибка сети не отменяет запись накладной. Она фиксируется в журнале регистрации. Повторная запись документа выполняет повторную безопасную отправку.
