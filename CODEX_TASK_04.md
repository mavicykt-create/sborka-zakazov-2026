# Codex Task 04 - главный экран и надёжность импорта

Работай в этом репозитории. Главный источник требований - `SPEC.md`.

Первые три этапа завершены: заказ импортируется, распределяется, собирается, проверяется, закрывается и выгружается в PDF.

Цель задачи: сделать главный терминал полноценным операционным экраном и не терять историю ошибок загрузки XLSX.

## Сделать

1. Добавить постоянный журнал каждой попытки импорта: успешной, повторной и ошибочной.
2. Хранить имя файла, SHA-256, результат, связанный заказ, реквизиты документа, число строк, предупреждения и понятную ошибку.
3. Не создавать заказ и частичные товарные строки при ошибке разбора.
4. Сохранить защиту от дублей по hash и по комбинации номера, даты и склада, включая конкурентную загрузку.
5. Добавить API истории импортов с фильтром результата и ограничением числа записей.
6. Добавить агрегированный API главного терминала: новые, в сборке, готовые, проблемные позиции, смена и ошибки импорта за 24 часа.
7. Добавить в React/Vite отдельный раздел `Главная` с текущими заказами, прогрессом, состоянием смены и блоком `Требует внимания`.
8. В `Требует внимания` показывать актуальные проблемные позиции и ошибки импорта.
9. Добавить раздел `Настройки` с безопасной диагностикой API/PostgreSQL и журналом импортов.
10. Не возвращать браузеру секреты, строку подключения, hash паролей и другие закрытые параметры окружения.
11. Обновить Prisma-схему, миграции и README.

## Рекомендуемый API

- `GET /api/dashboard`
- `GET /api/imports`
- `GET /api/settings`

## Автотесты

1. Реальный XLSX создаёт заказ и запись `SUCCESS`.
2. Повторная загрузка возвращает существующий заказ и записывает `DUPLICATE`.
3. Повреждённый XLSX возвращает понятную ошибку и записывает `FAILED`.
4. Главная сводка учитывает ошибку импорта и не раскрывает `passwordHash`.
5. Регрессия полного складского сценария и PDF продолжает проходить.

## Не делать пока

- Android-приложение;
- распознавание речи и звуковые сигналы;
- Gmail API;
- интеграцию 1С;
- внешнюю авторизацию;
- автоматическую отправку уведомлений.

В конце примени миграции, импортируй реальный и повреждённый XLSX, проверь главный терминал в браузере, затем запусти тесты, линтер и сборку.
