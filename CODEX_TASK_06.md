# CODEX_TASK_06 — Веб-режим сборщика

## Цель

Добавить внутренний веб-режим для сборщика без Android-приложения, Gmail и голосового управления.

## Требования

1. Вход сборщика по существующим логину и паролю.
2. Серверная сессия с ограниченным сроком действия и возможностью выхода.
3. Пароли и токены не возвращаются API и не хранятся в базе в открытом виде.
4. Сборщик видит только назначенные ему незавершённые позиции.
5. Доступны действия: начать, взять, не найдено, пропустить и отменить последнее действие.
6. Сервер проверяет, что позиция назначена вошедшему сборщику.
7. Интерфейс работает на телефоне и настольном экране.
8. Добавлены интеграционные проверки авторизации и личной очереди.

## Не входит в этап

- Gmail и автоматическое получение файлов.
- Нативное Android-приложение.
- Голосовое управление.
- Публичная интернет-аутентификация административного терминала.
